# Brand

## The name

**DZO** — three letters. Reads *Dee-Zee-Oh* or, informally, *dzoh*. It expands to:

**Decay · Zero · Open**

Three words matching the three phases of the tool:

- **Decay** — the 99% opening tax decays to zero over three seconds
- **Zero** — we wait for the tax to reach the ceiling (asymptotically zero)
- **Open** — we open the position at the arrival block

Every touchpoint of the brand carries this expansion once: README subtitle, docs footer, the wordmark line in the terminal, the OG description of the repo, the pinned tweet.

## The line

`wait for zero`

Short, technical, a pun (waiting for the tax to hit zero = waiting for the mathematical zero of a decay curve). Sits under the wordmark, on the Twitter bio, on the OG image, on the favicon's alt text.

## The mark

Monogram: **D · Z · O** stacked or inline with **O** rendered as a perfect circle representing zero. In loop form, an **O** with a crosshair inside — target-lock aesthetic without being military.

The mark is line-only, never filled. Stroke weight uniform. No gradients, no shadows, no bevels, no depth.

## Palette

| Token | Hex | Use |
|---|---|---|
| `bg` | `#0A0A0A` | primary background (terminal-black) |
| `surface` | `#141210` | cards, drawers |
| `border` | `#2A2724` | dividers, table lines |
| `accent` | `#00FF88` | wordmark, FIRE verdicts, live signals, links |
| `warn` | `#FFB347` | WATCH verdicts, warnings |
| `mute` | `#4A4A4A` | SKIP, muted state |
| `text` | `#F5F1E8` | primary text |
| `textMuted` | `#8B8680` | secondary text, metadata |
| `red` | `#FF5555` | errors, session-budget-reached, stop-loss hit |

Only one accent color. Green is the only living element on a dark surface. Anything that is not green is either text or muted.

## Typography

| Slot | Font | Weight |
|---|---|---|
| Wordmark | Berkeley Mono (fallback: JetBrains Mono) | 700 |
| Terminal / code | Berkeley Mono / JetBrains Mono | 400 |
| Docs headings | Inter | 600 |
| Docs body | Inter | 400 |
| Numeric readouts | JetBrains Mono | 500 |

Never mix serif. No display font. Type is technical, not editorial.

## Voice

- Sentences under 25 words most of the time
- Numbers over adjectives
- Cite blocks and dates for measured claims
- No exclamation marks anywhere
- Never call the user "we" — DZO does, you do
- Never promise
- When declining, say the rule that declined

Sample line: *"pass · dev buy 12.4% > maxDevShare 8% · fingerprint 0.83 vs 0.7"*

## Anti-patterns

- Neon crypto candles
- 3D-rendered coins
- Lamborghini imagery
- "To the moon" language
- Emoji chains
- Discord banner ads
- Meme fonts (Comic Sans, Impact, etc.)
